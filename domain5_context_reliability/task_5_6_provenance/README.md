# Task 5.6 — Information Provenance & Multi-Source Synthesis

> Status: **skeleton** — theory captured from the study notes; demo not built yet.

## Theory

- Claim-source mapping: claim, source URL, document name, relevant excerpt, publication date.
- Conflicts: annotate both values with attribution - never pick a winner.
- Different dates = trend; same date, different method = methodology note; same everything = flag as unexplained.
- Render by content: financial -> tables, news -> prose, technical -> structured lists.

## Exam trap

Choosing the most recent source; paraphrasing away attribution in synthesis; one uniform format for everything.
